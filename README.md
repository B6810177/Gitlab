## DC Circuit Calculator

โปรแกรมสำหรับคำนวณและวิเคราะห์วงจรไฟฟ้ากระแสตรง (DC) ทั้งตัวต้านทานแบบอนุกรม ขนาน และผสม โดยรับค่าแรงดันไฟฟ้าและค่าความต้านทานเพื่อคำนวณหาความต้านทานรวม กระแสไฟฟ้า และกำลังไฟฟ้า
