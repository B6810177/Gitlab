{# ---------- ENGINEERING MODEL ---------- #}

03 · ENGINEERING MODEL

แบบจำลอง DC ของ BJT NPN · Common Emitter

แบบจำลองนี้ใช้สมมติฐาน β คงที่ และ VBE คงที่ (Forward-Active Approximation) โดยแทนวงจรแบ่งแรงดันที่เบสด้วยแหล่งจ่ายเทียบเท่าเทเวนิน แล้วแก้สมการลูปเบส–อิมิตเตอร์เพื่อหา IB ก่อนคำนวณปริมาณ DC ที่เหลือทั้งหมด

Fixed Bias

IB = (VCC − VBE) / RB

ไบอัสผ่าน RB ตัวเดียวจาก VCC ไปยังเบส ไม่มี RE ช่วย stabilize

Emitter Bias

IB = (VCC − VBE) / [RB + (β + 1)RE]

มี RE ที่อิมิตเตอร์ ทำให้กระแสไบอัสเสถียรขึ้นเมื่อ β เปลี่ยน

Voltage Divider Bias ใช้ในแลปนี้

VTH = VCC R2 / (R1 + R2)

RTH = R1 ∥ R2

IB = (VTH − VBE) / [RTH + (β + 1)RE]

R1–R2 ตรึงแรงดันที่เบส และ RE ป้อนกลับลบให้ Q-point นิ่งที่สุด

สมการที่ใช้หา Q-point

  • IC = β IB  ·  IE = (β + 1) IB
  • VE = IE RE
  • VC = VCC − IC RC
  • VCE = VC − VE

เงื่อนไขภูมิภาคการทำงาน

  • Cutoff — IB ≈ 0
  • Saturation — VCE ≤ 0.2 V
  • Forward Active — VCE > 0.2 V และ IB > 0

หน่วย: V เป็นโวลต์ (V), กระแสเป็น mA / µA, ความต้านทานเป็น Ω หรือ kΩ (1 MΩ = 1,000 kΩ) — Q-point นี้เป็นค่าอ้างอิงให้ ngspice ใช้ใน analysis แบบ dc / ac / tran ด้านล่าง
