ผมใช้ AI ช่วยเขียนและอธิบายโปรแกรมคำนวณวงจร DC รวมถึงช่วยแก้ README ที่มีข้อความ merge ค้างอยู่
ผมตรวจสูตรคำนวณความต้านทานรวม กระแส และกำลังไฟฟ้าด้วยตนเอง
จากนั้นผมรันทดสอบโปรแกรม พบว่าการทดสอบทั้ง 7 ข้อผ่าน
ข้อผิดพลาดที่พบคือ README มีเครื่องหมาย conflict จากการ merge ทำให้อ่านไม่รู้เรื่อง
ผมแก้โดยเอาเครื่องหมายออกและรวมเนื้อหาที่ต้องการไว้ในไฟล์เดียว
Commit คือบันทึกการเปลี่ยนแปลงไว้ใน Git ส่วน Push คือส่ง commit ขึ้น GitHub
Clone คือคัดลอก repository จาก GitHub ลงเครื่อง การตรวจ Tests บนเครื่องใหม่ช่วยเช็กว่าโค้ดรันได้ในสภาพแวดล้อมนั้นจริง
