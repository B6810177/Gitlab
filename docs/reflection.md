# Reflection — สิ่งที่ได้เรียนรู้จาก Lab นี้

## 1. Web App จริงทำงานอย่างไร

ก่อนทำ lab นี้เข้าใจว่าเว็บคือ "ไฟล์ HTML ที่คำนวณเอง" แต่จากการสร้างแอปนี้
เห็นชัดว่า Web App มีสองฝั่ง:

- **Frontend** (Browser) — แสดงฟอร์มและผลลัพธ์จาก HTML/CSS ที่ Server ส่งมา
- **Backend** (Flask + Python) — รับ HTTP request, ตรวจข้อมูล, คำนวณ แล้วส่ง HTML กลับ

การคำนวณ DC bias เกิดขึ้นใน Python ทั้งหมด ไม่ใช่ใน Browser
(ยกเว้นหน้า static ที่เป็นเวอร์ชันเสริมของ Lab 2)

## 2. Frontend / Backend / Template / Static / HTTP

- **Template (Jinja2)** คือ HTML ที่มีช่อง `{{ }}` / `{% %}` ให้ Server เติมค่าก่อนส่งให้ Browser
  จึงไม่ใช่ HTML นิ่ง ๆ และไม่ใช่ไฟล์ที่คำนวณเอง
- **Static resources** (`static/style.css`, `static/app.js`) คือไฟล์ที่ Browser โหลดตรง
  ไม่ผ่านการประมวลผลของ Jinja2 — ใช้จัดหน้าตาและ (ในเวอร์ชัน static) คำนวณฝั่ง client
- **HTTP Request** คือการส่งข้อมูลฟอร์มด้วย `POST /` ไปยัง Flask
  แล้ว Flask ตอบกลับเป็น HTML หน้าใหม่ที่มีผลลัพธ์
- **Source code ที่แยกหน้าที่** ทำให้แก้สมการโดยไม่แตะ HTML และแก้หน้าตาโดยไม่แตะสมการ

## 3. สิ่งที่ลงมือทำ

- สร้าง Flask app รับค่า VCC, R1, R2, RC, RE, β, VBE ผ่านฟอร์ม
- แยกโมดูลวิศวกรรม (`bjt_bias/bias.py`) ออกจาก HTTP (`app.py`)
- ตรวจอินพุตและรองรับเลขหลักเยอะ/เครื่องหมาย comma เช่น `1,000,000`
- แสดงผล VB, VE, VC, VCE, IC, IB, IE, VTH, RTH พร้อมบอก region
  (Forward Active / Cutoff / Saturation)
- เขียน unittest ตรวจทั้งสมการและ HTTP flow (16 tests)
- เก็บประวัติงานบน GitHub และรันเว็บผ่าน `http://127.0.0.1:5000/`

## 4. การใช้ AI อย่างมีวิจารณญาณ

AI ช่วยร่างโครงสร้างและเขียนโค้ดได้เร็วขึ้น แต่สิ่งที่ต้องตรวจเองคือ:

- **สมการและตัวเลข** — เทียบค่าอ้างอิงที่คำนวณมือ/ตำรากับผลของโปรแกรม
  (เช่น VCE = 8.052 V, IC = 1.230 mA สำหรับชุดค่า R1=100k, R2=22k, RC=2.2k, RE=1k)
- **กรณีขอบ** — อินพุตติดลบ/ศูนย์, VBE ผิดช่วง, ค่าที่ทำให้อิ่มตัว/ตัดไฟ
- **พฤติกรรมหน้าเว็บ** — ฟอร์มว่างเริ่มต้น, ข้อความ error, การเลื่อนไปผลลัพธ์
- **ความหมายของโค้ด** — ต้องอธิบายได้ว่าทำไมแยกไฟล์แบบนี้ ไม่ใช่แค่กดรับโค้ด

## 5. ปัญหาที่เจอและวิธีแก้

| ปัญหา | วิธีแก้ |
|---|---|
| ตัวเลขหลักเยอะถูกตัดเมื่อใช้ `type="number"` | เปลี่ยนเป็น `type="text"` + `inputmode="decimal"` และตัด comma ก่อนแปลง |
| หน้าเว็บค้างค่าเก่าหลังแก้ template | เพิ่ม `Cache-Control: no-store` ให้ response HTML |
| ต้องรองรับหลายโหมดไบอัส | แยกฟังก์ชัน calculate ต่อโหมด และเลือกจาก `mode` ใน route |
| ผลลัพธ์อยู่ไกลจากฟอร์ม | เลื่อนหน้าไปที่ผลลัพธ์อัตโนมัติหลังคำนวณ |
